# 瞬電(しゅんでん)
プランナー 2名/プログラマー 3名/デザイナー 5名/声優 2名
計12名で制作したアクションゲームです。
  
制作期間 2024/11/29～2025/03/31
  
## 概要説明
コンセプトは「神速の居合で斬り捨てろ」  
  
近未来の東京を舞台に、暴走したアンドロイドを破壊するため  
アンドロイドの忍者少女が夜のビル群を跳びまわる。  
  
居合とクナイを駆使し、敵を素早く斬り捨てろ！  
  
敵を連続で倒すと「コンボ」が加算。敵から得られる報酬が増加する。  
  
ステージをクリアするごとに主人公をエディット可能！  
敵を倒して入手したBLOOD（ゲーム内通貨）で主人公を強化せよ！  
  
忍者×居合３Dアクション！！

## AppFrameについて
AppFrameは本作だけでなく今後の作品制作でも活用できる汎用的な機能をまとめた自作フレームワークです。  
主な機能としては下記のものがあります。  
### □シーン管理機能(SceneBase, SceneServer)  
各画面（プレイ画面、メニュー、UI など）を SceneBase を継承したクラスとして実装することで、SceneServer でシーンごとのライフサイクル（更新/描写/削除）を一元管理することができます。  
レイヤー番号に応じた描写やモーダル遷移に対応することで、UIなどの画面の実装を安全かつ容易に行えるようにしています。  
### □データ管理機能(DataListBase, DataListServer)  
同種データの集合(3Dモデル、サウンド、ゲーム内のオブジェクト など)をDataListBaseを継承したクラスとして実装することで、DataListServerでデータリストの追加/削除/編集/列挙を一元管理することができるようになっています。  
データリスト単位で管理することにより、シーン間での安全なデータ共有を容易に行えるようにしています。
